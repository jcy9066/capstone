# 20260429 [FULL] H.264 실시간 스트림 모델 대시보드 결과

## 1. 작업 요약

Raspberry Pi에서 Python 코드를 실행하지 않고 `rpicam-vid`로 H.264 실시간 영상을 GPU 서버에 push할 수 있도록 서버에 H.264 스트림 수신 엔드포인트를 추가했다.

GPU 서버는 H.264 스트림을 `ffmpeg`로 디코딩해 BGR frame으로 변환하고, 기존 `FrameProcessor`를 통해 선택된 1~9번 모델 파이프라인으로 처리한 뒤 대시보드 `/video_feed`에 결과 프레임을 표시한다.

## 2. 수정 파일

```text
server/app.py
.env
README.md
docs/20260429_[FULL]_H264_실시간스트림_모델대시보드_plan.md
```

## 3. 추가된 서버 기능

추가 엔드포인트:

```text
POST /stream/h264
```

처리 흐름:

```text
HTTP request body로 H.264 byte stream 수신
ffmpeg subprocess stdin으로 전달
ffmpeg stdout에서 raw BGR frame 수신
FrameProcessor로 모델 추론 및 시각화
latest_result 및 current_frame 갱신
대시보드 /video_feed에서 결과 영상 표시
```

기존 `/frame`은 정지 이미지/JPEG 테스트용으로 유지했다.

## 4. 추가 설정

`.env`:

```env
STREAM_WIDTH=640
STREAM_HEIGHT=480
STREAM_FPS=15
```

서버는 H.264를 디코딩한 뒤 위 해상도/FPS 기준으로 raw frame을 처리한다.

## 5. 실행 방법

GPU 서버:

```bash
cd ~/capstone
uvicorn server.app:app --host 0.0.0.0 --port 21063
```

Raspberry Pi:

```bash
rpicam-vid -t 0 --codec h264 --inline --width 640 --height 480 --framerate 15 -o - | \
curl --http1.1 -v -N -X POST -T - \
  -H "Content-Type: video/H264" \
  -H "Transfer-Encoding: chunked" \
  "http://10.108.90.21:21063/stream/h264?robot_id=pi-01"
```

대시보드:

```text
http://10.108.90.21:21063
```

## 6. 파이프라인 선택

GPU 서버 `.env`에서 선택한다.

```env
PIPELINE=1
```

선택 가능한 값:

```text
1~9
```

변경 후 서버를 재시작하면 해당 파이프라인이 startup에서 1회 로드된다.

## 7. 검증 결과

수행:

```bash
python -m py_compile server/app.py
```

결과:

```text
문법 검사 통과
```

추가 확인:

```bash
ffmpeg -version
```

현재 작업 환경 결과:

```text
ffmpeg: command not found
```

따라서 H.264 실시간 스트림은 GPU 서버 환경에 `ffmpeg`를 설치한 뒤 테스트해야 한다.

## 8. 필요 조치

GPU 서버 conda 환경 또는 시스템에 `ffmpeg`를 설치한다.

예시:

```bash
conda install -c conda-forge ffmpeg
```

또는 시스템 패키지:

```bash
sudo apt install ffmpeg
```

설치 후 서버를 재시작하고 Raspberry Pi에서 `rpicam-vid | curl` 명령을 실행한다.
