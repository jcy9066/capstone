# 20260429 [FULL] H.264 스트림 영상 미표시 디버그 결과

## 1. 작업 요약

H.264 stream이 대시보드에 표시되지 않는 원인을 구분하기 위해 서버에 stream 상태 계측을 추가했다.

## 2. 수정 파일

```text
server/app.py
```

## 3. 추가 기능

추가 엔드포인트:

```text
GET /api/stream_status
```

응답에 포함되는 정보:

```text
connected
robot_id
bytes_received
frames_decoded
last_frame_at
last_error
ffmpeg_stderr_tail
has_current_frame
received_fps
stream_width
stream_height
stream_fps
```

## 4. 확인 방법

GPU 서버를 재시작한다.

```bash
cd ~/capstone
uvicorn server.app:app --host 0.0.0.0 --port 21063
```

Raspberry Pi에서 stream push 명령을 실행한다.

```bash
rpicam-vid -t 0 --codec h264 --inline --width 640 --height 480 --framerate 15 -o - | \
curl --http1.1 -v -N -X POST -T - \
  -H "Content-Type: video/H264" \
  -H "Transfer-Encoding: chunked" \
  "http://10.108.90.21:21063/stream/h264?robot_id=pi-01"
```

GPU 서버에서 상태를 확인한다.

```bash
curl http://localhost:21063/api/stream_status
```

## 5. 해석 기준

```text
bytes_received = 0
-> Raspberry Pi stream이 서버에 도달하지 않음

bytes_received 증가, frames_decoded = 0
-> 서버까지는 도달하지만 ffmpeg 디코딩 실패

frames_decoded 증가, has_current_frame = false
-> 디코딩 이후 frame publish 문제

frames_decoded 증가, has_current_frame = true
-> 서버는 정상이며 /video_feed 또는 브라우저 표시 문제

last_error 또는 ffmpeg_stderr_tail 존재
-> 해당 ffmpeg 오류 메시지를 우선 해결
```
