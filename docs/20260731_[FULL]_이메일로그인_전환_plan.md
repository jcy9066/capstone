# 이메일 로그인 전환 계획

## 목표

로그인 ID를 전체 이메일 주소로 사용하고, 회원가입 화면에서 별도 로그인 ID 입력 및 중복 확인을 제거한다.

## 범위

- `users.login_id` 열을 조회하거나 쓰지 않는다.
- 최종 가입 시 기존 `users`의 이메일·비밀번호·이름·전화번호·사번 열만 사용한다.
- 로그인 입력은 전체 이메일과 비밀번호로 받는다.
- 이메일 인증 JWT 흐름은 그대로 유지한다.
- DB 테이블 생성·수정 및 마이그레이션은 하지 않는다.

## 검증

- Python 문법 및 인증 서비스 테스트
- 브라우저 로그인 스크립트 문법 검사
