# 중복 이메일 가입 처리 작업 계획서

## 목적

이미 가입된 이메일이 인증번호 발송과 인증 절차를 통과한 뒤 최종 가입 단계에서만 실패하는 흐름을 바로잡고, 중복 이메일 오류 문구가 깨져 보이는 문제를 해결한다.

## 작업 범위

1. 이메일 인증번호 발송 전 `users` 테이블에서 이메일 중복 여부를 확인한다.
2. 중복이면 HTTP 409와 `이미 가입된 이메일입니다.` 메시지를 반환한다.
3. 최종 가입 단계의 중복 이메일 409 메시지를 정상 한글로 복구한다.

## 구현 방안

- `server/auth_service.py`의 JWT 기반 이메일 인증 발송 함수에 기존 가입 이메일 조회를 추가한다.
- 기존 최종 가입 단계의 중복 검사는 유지해 동시 가입 요청에도 DB 단계에서 다시 방어한다.
- 관련 오류 메시지만 UTF-8 한글 문자열로 교체한다.

## 검증 계획

- Python 문법 검사를 실행한다.
- 중복 이메일 검사 코드와 409 메시지가 두 가입 단계에 모두 있는지 정적 확인한다.
