# 20260429 [FULL] 통합 서버 단일 포트 21063 변경 결과

## 1. 작업 요약

Raspberry Pi와 GPU 서버 연결에 필요한 포트를 `21063` 하나로 통일했다.

GPU 서버와 Control Dashboard는 분리하지 않으므로, 대시보드와 모든 API/WebSocket도 같은 포트에서 동작한다.

```text
Dashboard: http://10.108.90.21:21063
Frame API: http://10.108.90.21:21063/frame
Status API: http://10.108.90.21:21063/status
Robot WebSocket: ws://10.108.90.21:21063/ws/robot/pi-01
```

## 3. 변경 내용

`.env`:

```env
SERVER_PORT=21063
SERVER_BASE_URL=http://10.108.90.21:21063
```

Python 기본값:

```text
perception/config/settings.py -> 21063
raspberry/pi_client.py -> http://10.108.90.21:21063
server/app.py -> SERVER_PORT 기본값 21063
```

README와 관련 문서의 실행 예시도 `21063` 기준으로 정리했다.

`server/app.py`에 직접 실행 진입점도 추가했다.

```bash
python server/app.py
```

위 명령은 `.env`의 `SERVER_HOST`, `SERVER_PORT`를 읽어 실행한다.

## 4. 실행 기준

GPU 서버:

```bash
cd ~/capstone
uvicorn server.app:app --host 0.0.0.0 --port 21063
```

브라우저:

```text
http://10.108.90.21:21063
```

Raspberry Pi:

```bash
cd ~/capstone
python raspberry/pi_client.py
```

## 6. 주의사항

`http://10.108.90.21:21063`에서 `{"detail":"Not Found"}`가 뜨면 포트 문제가 아니라, `21063`에 통합 서버가 아닌 다른 FastAPI 앱이 떠 있을 가능성이 높다.

이 경우 기존 프로세스를 종료하고 프로젝트 루트에서 다음 명령으로 다시 실행한다.

```bash
uvicorn server.app:app --host 0.0.0.0 --port 21063
```
