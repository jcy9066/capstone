# 20260429 [FULL] 통합 서버 포트 변경 계획 (폐기)

> 폐기됨: 최종 결정은 `21063` 단일 포트 사용이다. 이 문서는 중간 검토 기록으로만 남긴다.

## 1. 작업 목표

기존 테스트 서버 또는 다른 FastAPI 앱이 `21063` 포트를 사용 중일 수 있으므로, Control Dashboard를 포함한 통합 서버의 포트를 변경하는 방안을 검토했다.

이번 구조에서는 GPU 서버와 Control Dashboard를 분리하지 않으므로, 통합 서버의 API와 Dashboard는 같은 포트인 `21063`를 사용한다.

```text
Dashboard: http://10.108.90.21:21063
Frame API: http://10.108.90.21:21063/frame
Status API: http://10.108.90.21:21063/status
Robot WebSocket: ws://10.108.90.21:21063/ws/robot/pi-01
```

## 2. 수정 대상

```text

perception/config/settings.py
README.md
docs/20260429_[FULL]_Push_WebSocket_통합서버_result.md
```

## 3. 변경 내용

- `SERVER_PORT` 기본값을 `21063`로 변경한다.
- `SERVER_BASE_URL` 기본값을 `http://10.108.90.21:21063`로 변경한다.
- Raspberry Pi client가 기본적으로 `21063` 서버에 연결되도록 한다.
- README 실행 명령과 curl 테스트 명령을 `21063` 기준으로 갱신한다.
- 필요 포트가 늘어날 경우 `21063`부터 1씩 증가한 포트를 사용한다는 기준을 문서화한다.

## 4. 검증 계획

```bash
uvicorn server.app:app --host 0.0.0.0 --port 21063
curl http://localhost:21063/
curl http://localhost:21063/api/pipelines
```
