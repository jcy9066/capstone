# 20260429 [FULL] 통합 서버 단일 포트 21063 변경 계획

## 1. 작업 목표

Raspberry Pi와 GPU 서버 연결에 사용할 포트를 `21063` 하나로 통일한다.

GPU 서버와 Control Dashboard는 분리하지 않으므로, 대시보드와 모든 API/WebSocket도 같은 포트 `21063`에서 제공한다.

```text
Dashboard: http://10.108.90.21:21063
Frame API: http://10.108.90.21:21063/frame
Status API: http://10.108.90.21:21063/status
Robot WebSocket: ws://10.108.90.21:21063/ws/robot/pi-01
```

## 3. 작업 내용

- `SERVER_PORT`를 `21063`으로 되돌린다.
- `SERVER_BASE_URL`을 `http://10.108.90.21:21063`으로 되돌린다.
- Raspberry Pi client 기본 접속 주소를 `21063`으로 되돌린다.
- README 실행 예시와 curl 테스트 예시를 `21063` 기준으로 정리한다.
- 이전 `21064` 변경 문서는 더 이상 권장하지 않는 과거 변경으로 표시한다.

## 4. 검증 계획

```bash
python -m py_compile server/app.py perception/config/settings.py raspberry/pi_client.py
```

```bash
uvicorn server.app:app --host 0.0.0.0 --port 21063
```
