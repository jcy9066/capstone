# 20260429 [FULL] H.264 스트림 영상 미표시 디버그 계획

## 1. 문제

대시보드는 접속되고 시간 표시도 정상이나, Raspberry Pi에서 H.264 push 명령을 실행해도 실시간 영상이 대시보드에 표시되지 않는다.

## 2. 가능 원인

```text
1. GPU 서버에 ffmpeg가 없거나 실행 실패
2. /stream/h264 요청이 서버까지 도달하지 않음
3. ffmpeg가 H.264를 디코딩하지 못함
4. 디코딩 frame은 나오지만 current_frame 갱신이 안 됨
5. 모델 추론이 너무 오래 걸려 첫 프레임 publish가 지연됨
6. /video_feed는 정상이나 latest frame이 아직 없음
```

## 3. 수정 방향

`server/app.py`에 스트림 디버그 상태를 추가한다.

추가할 정보:

```text
stream connected 여부
마지막 stream 연결 시각
수신 byte 수
디코딩 frame 수
마지막 디코딩 오류
ffmpeg stderr
latest frame 존재 여부
```

추가 엔드포인트:

```text
GET /api/stream_status
```

또한 `/stream/h264` 연결 시 ffmpeg stderr를 백그라운드에서 읽어 로그에 출력하게 한다.

## 4. 검증

Raspberry Pi에서 stream push 실행 후 GPU 서버에서 확인한다.

```bash
curl http://localhost:21063/api/stream_status
```

확인 기준:

```text
bytes_received 증가 -> Pi에서 서버까지 도달
frames_decoded 증가 -> ffmpeg 디코딩 성공
has_current_frame true -> 대시보드 표시 가능 상태
last_error 존재 -> 해당 오류부터 해결
```
