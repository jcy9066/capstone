# 20260731 [FULL] 이메일 로그인 간소화 계획

## 목표

- 이메일 주소를 로그인 식별자로 사용한다.
- 회원가입은 이메일 인증 후 비밀번호와 비밀번호 확인만 받는다.
- 별도 로그인 ID 입력과 `/api/auth/availability` 중복 확인 호출을 제거한다.

## 변경 범위

- `frontend/services/static/login_auth.js`: 로그인 입력을 이메일로 변경하고, 가입 ID·이름·전화번호·사번 UI 및 중복 확인 호출을 제거한다.
- `server/auth_service.py`: 이메일로 로그인하고, 이메일 인증된 가입 요청에서 비밀번호만 검증해 사용자를 생성하도록 변경한다.
- `data/database/init_schema.sql` 및 기존 가입 마이그레이션: 가입에 더 이상 쓰지 않는 사용자 부가 정보를 선택 값으로 전환하고 `login_id` 의존성을 없앤다.

## 검증

- Python 문법 검사와 인증 단위 테스트를 실행한다.
- 브라우저 스크립트 문법을 검사하고 `/api/auth/availability` 호출이 제거됐는지 검색한다.
