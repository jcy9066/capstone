# 저장 지도 이름 변경 계획

## 목표

대시보드의 저장 지도 선택 창에서 지도 카드를 우클릭해 지도 이름을 변경할 수 있게 한다.

## 구현 범위

1. 지도 카드의 우클릭 메뉴와 이름 입력 모달을 추가한다.
2. 인증 및 CSRF 검증을 거치는 이름 변경 API를 추가한다.
3. 선택한 지도에 속하는 `.pgm`, `.yaml`, `.meta.json`, `.raw.json` 파일을 하나의 작업으로 안전하게 변경하고, YAML의 이미지 참조와 메타데이터를 갱신한다.
4. 현재 선택/활성 지도 상태가 이름 변경 전 지도를 가리키면 해당 상태도 새 이름으로 갱신한다.
5. 유효한 지도 이름, 경로 이탈, 파일 충돌을 서버에서 검증하고 실패 시 기존 파일 상태를 보존하도록 한다.

## 제약 및 검증

- `navigation/` 아래의 ROS 코드 파일은 수정하지 않는다. 실행 중 실제 지도 데이터는 API 요청이 있을 때만 변경된다.
- 임의 경로나 심볼릭 링크를 이용한 파일 접근을 허용하지 않는다.
- 기존 지도 불러오기와 AMCL 초기 위치 설정 기능은 유지한다.
- Python 문법 검사와 프런트엔드 정적 점검으로 변경을 확인한다.
