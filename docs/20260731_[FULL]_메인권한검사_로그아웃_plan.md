# 메인 권한 검사 및 로그아웃 계획

## 목표

비로그인 사용자가 `/main`에 접근하면 `/login`으로 이동시키고, 대시보드 사이드 패널에서 로그아웃할 수 있게 한다.

## 구현 범위

- `/main`의 인증 여부 검사와 리디렉션을 확인·보완한다.
- 기존 세션 로그아웃 API를 재사용한다.
- 왼쪽 상단 메뉴 패널에 로그아웃 버튼을 추가하고 CSRF 토큰을 포함해 API를 호출한다.
- 로그아웃 성공 시 `/login`으로 이동한다.

## 검증

- 서버 Python 문법 검사
- 대시보드 JavaScript 문법 검사 가능 여부 확인
