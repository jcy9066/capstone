# JWT 이메일 인증 전환 계획

## 목표

이메일 인증 과정에서 데이터베이스 테이블을 생성하거나 변경하지 않는다. 인증번호 검증 상태는 짧은 만료 시간의 서버 서명 JWT와 HttpOnly 쿠키로 처리하며, 최종 가입 완료 시에만 `users` 테이블에 사용자를 생성한다.

## 구현 범위

- DB 기반 `email_verifications` 저장·조회·재발송/시도 제한을 제거한다.
- Gmail SMTP로 6자리 인증번호를 전송한다.
- 인증번호 검증 전용 JWT와 가입 허가 JWT를 각각 짧은 만료 시간으로 발급한다.
- 브라우저 JavaScript가 JWT 원문에 접근하지 못하도록 HttpOnly 쿠키를 사용한다.
- 이메일 인증 성공 후에만 회원가입 API가 `users`에 INSERT하도록 강제한다.
- 스키마 및 마이그레이션 파일을 만들거나 수정하지 않는다.

## 검증

- 인증 서비스 단위 테스트를 JWT 흐름에 맞춰 갱신한다.
- Python 문법 검사와 인증 관련 테스트를 실행한다.
