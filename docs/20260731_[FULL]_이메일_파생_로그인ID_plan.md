# 이메일 파생 로그인 ID 전환 계획

## 목표

`users` 테이블을 변경하지 않고, 가입 이메일의 `@` 앞부분을 로그인 ID로 사용한다. 가입 화면의 임의 로그인 ID 입력란과 해당 중복 확인 기능을 제거한다.

## 구현 범위

- 최종 가입 시 `login_id` 열을 읽거나 쓰지 않는다.
- 가입 이메일의 로컬 파트(첫 `@` 앞부분)를 로그인 ID로 파생한다.
- 동일한 로컬 파트를 가진 다른 도메인 이메일의 중복 가입을 애플리케이션에서 차단한다.
- 로그인은 파생 로그인 ID와 비밀번호로 처리한다.
- 프런트엔드에서 별도 ID 입력란·중복 확인을 제거하고 이메일 인증 후 비밀번호와 기존 가입 정보만 받는다.
- DB 테이블 생성·ALTER·DROP·마이그레이션은 하지 않는다.

## 검증

- 인증 서비스 단위 테스트와 Python 문법 검사를 수행한다.
- 브라우저 코드 문법을 검사한다.
